# Code signing policy

## Project

**USTA Practical Automation Tools** is an open-source collection of small production-workflow utilities. Its CorelDRAW component, **USTA Smart Node Cleaner v0.73**, is distributed as VBA source and a CorelDRAW GMS macro project.

Source repository: https://github.com/corniykot/usta-practical-automation-tools

License: [MIT](LICENSE).

## Current status

- The repository contains source code and an existing `.gms` project file.
- **No Windows installer is currently signed or endorsed by SignPath Foundation.**
- The committed binary GMS file was uploaded separately; it is not yet generated by a published automated build from repository source.
- A GitHub Actions workflow now compiles an unsigned Inno Setup EXE from the checked-in GMS binary. It has not yet been verified by a successful build run or accepted by SignPath Foundation.
- The GMS is still manually produced, so its provenance relative to the VBA source remains an outstanding signing-review question.

## Planned signing workflow

1. Keep reviewed source and installer scripts in the public repository.
2. Build the installer from a fixed source revision in the [GitHub Actions workflow](.github/workflows/build-usta-installer.yml), with clear artifact inputs and build logs.
3. Make the unsigned installer artifact available for signing from that build pipeline rather than uploading arbitrary local executables.
4. Request signing only for release artifacts built from approved, publicly traceable source revisions and workflows.
5. Publish signed release downloads with version, source revision and instructions for checking the Authenticode signature.

Changes to build and signing configuration should be reviewed before they are used for a release. Signing credentials, when provisioned, must never be committed to the repository.

## Verification

When signed installers become available, Windows users can inspect the **Digital Signatures** tab in file Properties or run:

```powershell
Get-AuthenticodeSignature .\USTA-Setup.exe | Format-List
```

A valid signature helps verify publisher identity and file integrity; it does not guarantee that Windows Smart App Control or other protection features will always allow execution.

## Security and privacy

USTA Smart Node Cleaner operates on the selected curve in the active CorelDRAW document. Its cleaning algorithm does not need network access. The optional **DONATE** and **EXPLORE** controls open PayPal or GitHub only when clicked.

Security reports: [usta.scripts@gmail.com](mailto:usta.scripts@gmail.com). Please avoid posting exploit details publicly before we can investigate.
